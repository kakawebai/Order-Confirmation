黑帽 SEO · 结构拆解

站群互链 → 权重汇集

同一主体控制的多个站点彼此互链（轮链 / 链轮），把外链与权重一层层导向主站； 同时用闭环互链维持每个卫星站的“活跃度”，让整张网看起来像自然形成的站群生态。

被识别后：集体降权 / K 站 仅作原理示意，不构成操作建议
实线 = 权重传递（卫星站 → 主站） 虚线 = 站群互链（轮链）
01

轮链（Ring）

卫星站首尾相连成环，环内互相传权、模拟“自然互链”，每个站再单独指向主站。

优点 主站不对外露链接，链条隐蔽
缺点 闭环规律性极强，是最容易被识别打掉的形态
02

链轮（星型 / Hub）

所有卫星站只指向主站，彼此不互链。传权路径最短，站与站之间不互相牵连。

优点 单链直达、不易连坐
缺点 卫星站自身权重低，得靠更多站点凑数量
03

链式（层级）

二级站 → 一级站 → 主站，逐层汇聚。层级越深，权重传递的损耗越大。

优点 结构最像“自然生态”
缺点 成本最高，且每过一层都在衰减

关键在“单向”

外圈虚线是站与站之间的互链（轮链、链轮），内圈金色实线是每个卫星站对主站的单向传权；主站不对外回链。

整张图最脆弱的地方也在这里：主站与这些站没有切断关系，一旦某一环被判定站群，关系图一画，主站就在图上。

04

搜索侧怎么认出这张网

不看单个站，而是找共性——同 IP / C 段、模板同源、whois 与注册时间集中、互链过于规律、内容高度相似、外链来源重叠。

同 IP / C 段 模板同源 whois 集中 互链规律 内容相似 外链重叠
05

代价不在域名，在主站

命中后是整网处罚：不是掉一个站，是关系图里的站一起降权，主站往往连坐，恢复周期以月计。

若池站来自入侵他人网站，还可能触及非法侵入 / 非法控制 / 破坏计算机信息系统类罪名；为灰产导流则可能涉帮信罪。

06

正规替代路径

把同一笔预算花在会被算法奖励的地方：

内容（原创、结构化）→ 外链（自然获取）→ 内链（清晰层次）→ 收录（搜索资源平台主动推送 / sitemap）。

慢，但不会某天早上整站从搜索结果里消失。

附

外链落点：全站链接，还是正文链接？

两种站群外链都真实存在，分工恰好对应图上的两条线：站群之间互链常用「全站链接」——改一处模板全站生效，成本最低； 站群指向主站的那一跳尽量用「正文链接」——文章里的一次锚文本，少而精。

A

全站链接（sitewide）

位置：导航栏、侧栏、页脚“合作伙伴”、友情链接区、面包屑。

特征：改一次模板，几万个页面全都带。早年“链接数直接等于权重”，这是站群标配。

B

正文链接（in-content）

位置：帖子正文里的锚文本、转载来源、编辑推荐、段落中间的一句。

特征：一次性、上下文相关、锚文本可长尾化；代价是需要内容承载。

C

夹在中间的一类

位置：列表页、聚合页、标签页、相关推荐、评论区、签名档、sitemap、隐藏 div。

特征：既不是纯导航，也不是真正文；识别成本低，传递效果也弱。

①

为什么全站链接不值钱

引擎对全站链接去重：同一源站对同一目标只按一次链接计。Google 明确只算一条，百度同样按同域去重；其余页面只消耗抓取预算。

而它留下最强的识别指纹：

  • 同批站、同套模板，每页底部都是同一份出站集合
  • 锚文本完全一致，主站锚文本单一、长尾为零
  • A / B / C 三个站的页脚“合作伙伴”是同一份名单

三条同时出现 ≈“这是一张站群网”。2013 年百度绿萝算法打击的就是链接买卖与链接农场；此后引擎对全站链接基本不判，直接折价。

②

为什么正文链接值钱

一次性、上下文相关、锚文本可分散。同样一根链接，写在行业话题的正文里，价值远高于页脚那行“友情链接”——代价是要有内容，这也是站群最贵的一块。

所以典型结构是分层投放：网内互链走全站（只为让爬虫在网里循环、把权重拢到几个枢纽站），枢纽站给主站的那几条走正文，锚文本分散、每站只放一两条。

这也是蜘蛛池要做“诱饵页”的原因：池站只挂页脚链接，页面质量太低，蜘蛛待不住，正文链接才生效。

③

三代玩法

阶段做法外链落点现状
早期 · 2010 前后模板底部友链，一次改全站全站链接已被绿萝 / 企鹅打掉
中期采集 + 伪原创，每站养几十篇正文为主 + 少量全站内容低质即被判
现在分层：网内互链造“生态”，导主站单点投放互链全站、导主站正文成本高、回报不稳定
④

怎么判断外链服务卖的是哪种

  • 链接位置：进的是页面模板（导航 / 页脚），还是某一篇正文？卖“全站高权重友链按月”的基本是过时货。
  • 容量与相关度：一个站能放几条、跟主站业务有没有语义关系？能放 5 条以上、什么行业都接的，就是纯导航位。
  • 自己验：site: 对方站，打开两三个页面，看同一条链接是不是每页都在、锚文本是不是一字不差。是 → 全站链接，对主站边际价值接近零，识别风险却最高。
⑤

一句话

全站链接是“便宜、但不值钱且显眼”；正文链接是“贵、但真正传权”。

引擎已经按“同一个源站只认一次链接”来计价——量大没用，位置和语境才有用。

值得抄的只有那条规律：一次性、上下文相关、锚文本自然。正规做法是让人在行业文章里自然地提你一次，而不是买 200 个站页脚里的一行字。
